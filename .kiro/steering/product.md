# Product Overview

## Doc App

A Flutter-based medical/healthcare application with user authentication and onboarding features.

### Key Features

- User authentication (login/signup)
- Onboarding flow
- Medical/healthcare focused functionality
- Multi-platform support (Android, iOS, Web, Desktop)

### Target Platforms

- Android (primary)
- iOS
- Web
- Windows, macOS, Linux (desktop support available)

### Current State

- Authentication system implemented with login/signup flows
- Onboarding screens
- Basic UI components and theming established
- Networking layer with API integration ready
